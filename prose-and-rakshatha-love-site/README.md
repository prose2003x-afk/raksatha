## 🚀 How to Push to GitHub & Host for Free on GitHub Pages

Open your terminal / PowerShell in this folder:
```bash
cd "C:\Users\ADMIN\.gemini\antigravity\scratch\prose-and-rakshatha-love-site"
```

### 1. Initialize Git & Commit:
```bash
git init
git add .
git commit -m "feat: romantic universe for Prose & Raksatha ❤️"
```

### 2. Connect to your GitHub Repository:
```bash
git branch -M main
git remote add origin https://github.com/<YOUR-USERNAME>/<YOUR-REPO-NAME>.git
git push -u origin main
```

### 3. Enable Free Live Hosting on GitHub Pages:
1. Go to your repository on **GitHub.com**.
2. Click **Settings** > **Pages** (on the left menu).
3. Under **Branch**, select **`main`** and **`/ (root)`**, then click **Save**.
4. Within 1 minute, your romantic site will be live at:
   `https://<YOUR-USERNAME>.github.io/<YOUR-REPO-NAME>/`
